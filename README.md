# Game crack status (crack-search)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `crack_search`, which checks whether a PC game has been cracked.

- The data comes from crackrelease.com and isitcracked.com. If the two sites disagree about the status of an entry with the same name (which is common with Hypervisor bypasses), the side marked `已破解` (cracked) or `Hypervisor 破解` (Hypervisor crack) wins, because a crack has a concrete release that can be checked, while "not cracked" only means that one site has no record of it; the other site's claim is listed as a note.
- The tool gives the crack status, how many days after release the game was cracked (or how long it has been out without being cracked), the DRM, the release and crack dates, the release group and links.
- A Chinese name is first converted to the English name through the Steam store before the lookup (because both sites only recognize English names); if Steam cannot find the full name, the tool shortens it one character at a time from the end and tries again, and the result then notes that the name is a guess and lists the other candidates.

## Parameters

The tool takes the following parameters:

| Parameter | Description |
|---|---|
| `query` | The game name, required; an English name gives the most accurate results |
| `limit` | The number of results from each source, 1–20, default 5 |
| `format` | `json` (default; structured data, one object per game) or `md` |

## Dependencies and notes

This section explains what the tool depends on and what happens when a source has problems.

- The tool uses only the Python standard library.
- The crackrelease.com data is scraped from the web page: if not a single result can be parsed from the page and the page has no "no results" marker from the site, the tool says clearly `页面结构变了` (the page structure has changed) instead of reporting that the game is not listed.
- The isitcracked.com data is fetched with the public anonymous Supabase key in its web page. If that key expires, this source reports that it is unavailable, and the main source still gives results as usual.
