# 游戏破解状态查询（miyu-scripts-crack-search）

给 Miyu 的脚本工具 `crack_search`：查一款 PC 游戏有没有被破解。

- 数据源：crackrelease.com 和 isitcracked.com。两站同名条目状态不一样时（常见于 Hypervisor 绕过），以说「已破解 / Hypervisor 破解」的一方为准——破解有具体发布可查，未破解只是某站库里没记录；另一方的说法作为附注列出。
- 给出状态、发售多少天后破解（或发售多久仍未破解）、DRM、发行和破解日期、发布组、链接。
- 中文名先经 Steam 商店转成英文名再查（两个站都只认英文名）；Steam 搜不到全名时从末尾逐字缩短再试，这时会注明是猜的并列出其他候选。

## 参数

| 参数 | 说明 |
|---|---|
| `query` | 游戏名，必填；英文最准 |
| `limit` | 每个来源几条，1–20，默认 5 |
| `format` | `json`（默认，结构化，一条游戏一个对象）或 `md` |

## 依赖与注意

- 只用 Python 标准库。
- crackrelease.com 是抓网页：页面里一条也解析不出、又没有站点的「无结果」标记时，会明说「页面结构变了」，而不是报「没收录」。
- isitcracked.com 用的是它网页里公开的 Supabase 匿名 key，key 过期了这一源会报不可用，主源照常出结果。
