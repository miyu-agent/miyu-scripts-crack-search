# 游戏破解状态查询（crack-search）

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `crack_search`，用来查询一款 PC 游戏有没有被破解。

- 数据来源是 crackrelease.com 和 isitcracked.com。如果两个网站上同名条目的状态不一样（常见于 Hypervisor 绕过），以标为 `已破解` 或 `Hypervisor 破解` 的一方为准，因为破解有具体的发布可以查证，而未破解只说明某个网站的库里没有记录；另一方的说法会作为附注列出。
- 工具给出破解状态、发售多少天后被破解（或者发售多久仍未被破解）、DRM、发行和破解日期、发布组以及链接。
- 中文名会先通过 Steam 商店转成英文名再查询（因为两个网站都只识别英文名）；如果 Steam 搜不到完整的名字，工具会从末尾逐字缩短再试，这时结果里会注明名字出于猜测，并列出其他候选。

## 参数

这件工具接受下面这些参数：

| 参数 | 说明 |
|---|---|
| `query` | 游戏名，必填；用英文名查询最准确 |
| `limit` | 每个数据来源列出的条数，1–20，默认 5 |
| `format` | `json`（默认，结构化的数据，每款游戏一个对象）或者 `md` |

## 依赖与注意

这一节说明工具依赖什么，以及数据来源出问题时会怎样。

- 工具只使用 Python 标准库。
- crackrelease.com 的数据是从网页上抓取的：如果页面里一条结果也解析不出来，又没有这个网站的「无结果」标记，工具会明确提示 `页面结构变了`，而不是报告这款游戏没有收录。
- isitcracked.com 的数据通过它网页里公开的 Supabase 匿名密钥获取。如果这个密钥过期了，这个数据来源会报告不可用，主数据来源仍然正常给出结果。
